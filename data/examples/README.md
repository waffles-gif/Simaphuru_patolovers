# Experimentos reproducibles

Los JSON reales se generan con la CLI y quedan en `artifacts/`, fuera de Git. No se incluyen cifras de QAOA inventadas para poblar la interfaz.

Para crear un fixture, generar primero un experimento real pequeño, revisar su tamaño y condición sintética y añadir una copia explícitamente identificada. El formato está descrito en `docs/CONTRACTS.md`.
